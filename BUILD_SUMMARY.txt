DATABASE SCHEMA
================================================================================

Collections Created:
├── users
│   ├── name: string
│   ├── email: string
│   ├── role: 'admin' | 'manager' | 'sales'
│   └── createdAt: timestamp

├── products
│   ├── name: string
│   ├── category: 'home-appliances' | 'sneakers'
│   ├── brand: string
│   ├── sku: string
│   ├── quantity: number
│   ├── costPrice: number
│   ├── sellingPrice: number
│   ├── supplier: string
│   ├── size?: string (sneakers)
│   ├── color?: string (sneakers)
│   ├── dateAdded: timestamp
│   └── lastUpdated: timestamp

└── sales
    ├── productId: string
    ├── quantity: number
    ├── price: number
    ├── totalAmount: number
    ├── recordedBy: string
    ├── recordedAt: timestamp
    └── notes?: string

5. Check reports
